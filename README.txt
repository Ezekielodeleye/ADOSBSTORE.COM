ADOSB WEBSITE

FILES
- index.html: website content
- style.css: design and responsive layout
- script.js: WhatsApp order buttons and mobile menu

HOW TO USE
1. Extract this ZIP.
2. Open index.html in a browser to preview.
3. Upload index.html, style.css and script.js to the same folder in your hosting service or GitHub repository.
4. The WhatsApp order buttons are already connected to +234 813 270 3300.
5. The website location is Odo Omu, Iseyin, Nigeria.

IMPORTANT ABOUT PRICES
You asked to show prices, but no actual prices were supplied. To avoid publishing made-up prices, the six products currently display “Price on request”. The product cards are ready for actual prices to be added once you provide them. The website also tells customers to ask for today's price on WhatsApp.

IMAGES
The sample product photos load from Unsplash, so an internet connection is needed to display them. Replace these image URLs in index.html with your own product photos whenever available.
